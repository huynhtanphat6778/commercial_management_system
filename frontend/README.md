# frontend/

Thư mục dành cho **Antigravity** (React + TypeScript + Tailwind CSS): website khách hàng, POS, Admin Dashboard.

Chưa khởi tạo mã nguồn. Đọc `docs/TASKS_ANTIGRAVITY.md` để biết phạm vi, quy tắc và thứ tự làm việc.
Frontend chỉ gọi `/api/v1`, không truy cập database, không tự tính giá/tồn kho/giá vốn.
